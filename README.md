# 🎯 JobTrack — Job Application Tracker

A clean, responsive web application for organizing job applications and tracking your job search progress.

## ✨ Features

* Add job applications with company names and job titles
* Track application dates and statuses
* Dashboard statistics for applications, interviews, and offers
* Delete applications
* Save application data in browser local storage
* Responsive interface

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Browser Local Storage
